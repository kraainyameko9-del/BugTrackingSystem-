# BugTracker / BugFlow Final Integrated Version

This final version uses the dark navy, gunmetal and electric-blue theme from the **Tsee 2** zip file, while keeping the working BugFlow Member 3 functionality.

## How to run

1. Open the folder.
2. Double-click `index.html`.
3. Use **Reset Demo Data** if you want to restore the 15 test tickets.

## What is included

- `index.html` - dashboard layout, create form, issue table, detail view and people/projects section.
- `css/styles.css` - all custom styling. No internal CSS is used.
- `js/data.js` - demo data and localStorage functions.
- `js/issueManager.js` - fixed Member 2 ticket logic.
- `js/ui.js` - Member 3 display and button connections.

## Demo flow

1. Show the ticket table.
2. Click one ticket to show the detailed view.
3. Edit the assigned person, priority or resolution date.
4. Save the changes.
5. Refresh the page to prove that localStorage kept the data.
